## 连接

| 项目 | 值 |
| --- | --- |
| 设备名 | ROSE Ceramics U |
| 传输 | 经典蓝牙 SPP / RFCOMM |
| 服务 UUID | `0CF12D31-FAC3-4553-BD80-D6832E7B3931` |
| 建链方式 | `createInsecureRfcommSocketToServiceRecord`（不加密） |

注意：耳机同一时间只接受一个 SPP 客户端。RoseLink 在跑时必须先停掉，否则连接会
一直阻塞。残留会话需要把耳机取出充电仓重新连接才能清。

## 帧格式

```
FF SEQ LEN BODY... CS AA        （手机 → 耳机）
DD SEQ ...                      （耳机 → 手机，LTV 结构）
```

- `SEQ`：8 位递增
- `LEN` = `len(BODY)`
- `CS` = `(FF + SEQ + LEN + BODY 全部字节) & 0xFF`

## 命令

### 读（带 FA 前缀）

| 功能 | BODY |
| --- | --- |
| 读全部信息 | `FA 01 07 08 09 0C 0D 0E 12 2A 2B 2C 2D 2E 2F 31 32 33 36 37 38 39 3A 3B 3C 3D 3F 45 46 49` |
| 读降噪模式 | `FA 09` |
| 读电量 | `FA 0C` |
| 读降噪强度 | `FA 2C` |

### 写（**不带前缀**，直接两字节）

| 功能 | BODY |
| --- | --- |
| 降噪 | `09 01` |
| 普通 | `09 02` |
| 通透 | `09 03` |
| 风噪 | `09 04` |
| 自适应降噪 | `09 05` |
| 深度降噪 | `09 06` |
| 动态自适应 | `09 07` |
| 降噪强度 | `2C NN`（1..5） |
| 通透强度 | `2D NN`（1..5） |

**关键坑**：设置命令如果写成 `02 09 01`（多一个 `02`），设备会回 ACK `FE 02`（拒绝），
不报错但也不生效。必须只发 `09 01`。

## 应答

- 成功：`dd SEQ 02 FE 00 CS AA`
- 拒绝：`dd SEQ 02 FE 02 CS AA`
- 模式上报：`dd SEQ 02 09 NN CS AA`
- 电量上报：`dd SEQ 04 0C LL RR CC CS AA`
  - 每字节 bit7 = 是否充电，低 7 位 = 百分比

### 电量字节细节（2026-11-17 平板实测补充）

| 现象 | 实测结论 |
| --- | --- |
| `0xFF` / `0x7F` | 该耳**未上报**（关机 / 脱离 / 未唤醒），不是 127%。解析时按"未知"处理 |
| 右耳充电位 | **右耳字节同样有 bit7 充电标志**。实测 `5d/de` = 左 93% 未充、右 94% 充电中 |
| 仓充电位 | 仓字节 bit7 同样是充电标志（尚未观测到置位，但结构一致） |
| 仓电量 | **是实时的**：耳机在仓充电期间仓电量持续下降（实测 82→81→79→78→77→76，约每 10 秒 1%） |
| 左耳充电位 | 正常（`5d` 未充 / `dd` 充电中） |

实测时序（raw 字节）：

```
5d/5e/2c   L93 未充  R94 未充  C44
5d/de/52   L93 未充  R94 充电  C82     ← 右耳回仓充电
dd/de/52   L93 充电  R94 充电  C82     ← 左耳也回仓
dd/5e/51   L93 充电  R94 未充  C81     ← 左耳仍在仓、右耳已取出
5d/5e/51   L93 未充  R94 未充  C81
```
